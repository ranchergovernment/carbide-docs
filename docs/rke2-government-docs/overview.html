Overview

Technical Preview

RKE2 Government is currently in technical preview and is not yet intended for production use.

What is RKE2 Government?​

RKE2 Government is a build of RKE2 provided by Rancher Government Solutions (RGS) that ships in a hardened, STIG-compliant configuration out of the box. It is available exclusively to RGS customers.

Standard RKE2 provides a hardened baseline that administrators finish configuring for their environment. RKE2 Government applies the required Kubernetes security configuration as part of the product itself, so administrators do not need to interpret, apply, and maintain individual hardening settings.

Features​

  • STIG-compliant by default. The Kubernetes control plane and supporting components are configured for STIG compliance automatically. No additional hardening configuration is required.
  • Integrated SELinux enablement. The RKE2 SELinux policies are installed and applied during the normal installation process, so there is no separate rke2-selinux package to locate, install, or maintain. See SELinux Packages for the base packages your nodes still need.
  • FIPS 140-3. RKE2 Government is FIPS 140-3 certified, verified, and validated.
  • Rancher compatibility. RKE2 Government is designed and tested both for hosting Rancher and for running as a downstream cluster managed by Rancher. The required Pod Security Admission (PSA) configuration and other compatibility settings are included.

Next Steps​

  • Review Considerations and Prerequisites for node prerequisites and important considerations when moving from standard RKE2 to RKE2 Government.
  • Follow the Installation guide to deploy RKE2 Government.
  • See Configuration to customize or override the STIG defaults.
